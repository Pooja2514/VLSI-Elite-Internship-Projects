# FIR Filter Design

## Objective
Design and simulate a Finite Impulse Response (FIR) filter.

## Features
- 4-tap FIR filter
- Uses fixed coefficients
- Processes input signals to produce filtered output

## Tools Used
- Verilog HDL
- EDA Playground / Quartus

## Description
The FIR filter is implemented using shift registers to store previous inputs. The output is calculated using multiply-accumulate operations based on current and past input values.

## Result
The FIR filter was successfully simulated, and correct filtered output was obtained.

## Conclusion
This task helped in understanding digital signal processing concepts and FIR filter implementation.
