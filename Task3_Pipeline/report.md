# Pipeline Processor Design

## Objective
Design a 4-stage pipelined processor to improve execution speed.

## Pipeline Stages
- Instruction Fetch (IF)
- Instruction Decode (ID)
- Execute (EX)
- Write Back (WB)

## Instructions Supported
- ADD
- SUB
- LOAD

## Tools Used
- Verilog HDL
- EDA Playground / Quartus

## Description
The processor is divided into four stages. Each stage performs a specific operation, and pipeline registers are used to pass data between stages. This allows multiple instructions to be processed simultaneously.

## Result
The pipeline processor was successfully simulated, and each stage operation was verified.

## Conclusion
This task helped in understanding pipelining concepts and how performance is improved in processors.
