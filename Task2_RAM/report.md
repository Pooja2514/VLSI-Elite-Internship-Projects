# RAM Design

## Objective
Design a synchronous RAM module with read and write functionality.

## Features
- 16 memory locations
- Each location stores 8-bit data
- Supports read and write operations

## Tools Used
- Verilog HDL
- EDA Playground / Quartus

## Description
The RAM is designed using sequential logic. Write operation occurs when write enable is high, and read operation occurs when write enable is low. All operations are synchronized with the clock signal.

## Result
The RAM module was successfully simulated. Data was correctly written and read from memory locations.

## Conclusion
This task provided understanding of memory design and sequential circuits in Verilog.
