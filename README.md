
# VLSI Internship Projects

This repository contains all tasks completed during my VLSI Internship.

## 📌 Tasks Completed

### 🔹 Task 1: ALU Design
- Operations: ADD, SUB, AND, OR, NOT
- Implemented using Verilog

### 🔹 Task 2: RAM Design
- Synchronous RAM with read/write operations

### 🔹 Task 3: Pipeline Processor
- 4-stage pipeline (IF, ID, EX, WB)

### 🔹 Task 4: FIR Filter
- 4-tap FIR filter using Verilog

## 🛠 Tools Used
- Verilog HDL
- EDA Playground / Quartus
- GTKWave

## 📊 Features
- Clean and modular code
- Testbenches for all designs
- Simulation outputs included.

## 🚀 Outcome
This internship helped me understand core VLSI concepts like ALU design, memory systems, pipelining, and digital filters.
